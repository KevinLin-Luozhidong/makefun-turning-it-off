# make.fun — Have You Tried Turning It Off?

Bounty: https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b
Prize: $10 shared by the top 10 entries.

## Entry

`main.py` — Python, standard library only. It writes one funny line that a
hopeless tech support agent says to a desperate customer to
`/output/entry.txt`. An AI judge compares the lines head to head in private
blind rounds: the twist must be unexpected, the agent's cheerful
uselessness is where the humour comes from, and the customer is never the
butt of it.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
python3 main.py                          # writes /output/entry.txt
```
